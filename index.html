Current project, since June 2026

Do genes work together differently in different types of breast cancer?

Doctors split breast tumors into subtypes like Luminal A, Luminal B and Basal-like, and each one grows and responds to treatment differently. I wanted to see if the way genes coordinate with each other also changes between subtypes, and if any of that is linked to how long patients live.

See the code on GitHub

  1. Step 1

    Build a network for each subtype

    For each of 500 genes, a random forest learns to predict that gene's activity from the other 499. The genes that help the most become its connections (this method is called GENIE3). Every network uses the same number of tumors, 141, so it's a fair comparison.

  2. Step 2

    Check what's real and what's noise

    Two networks will always look a bit different just by chance. So I shuffled the subtype labels and rebuilt the networks 10 times to see how big a random difference gets, and only kept connections that beat that.

  3. Step 3

    Keep what's stable

    I rebuilt each network 30 times on random 80% samples of the tumors. Hub genes and gene groups (modules) that kept showing up are the ones I trust.

  4. Step 4

    Test on new patients

    I checked if each module's activity is linked to survival in TCGA, then ran the exact same test on 1,892 patients from a second study called METABRIC.

Finding 1

The two luminal subtypes are wired alike, Basal-like is different

Luminal A and Luminal B share 397 of their top 1,000 connections. Basal-like only shares 152 with Luminal A and 134 with Luminal B.

After the shuffle test, 45 connections really differ between Basal-like and Luminal A, and 51 between Basal-like and Luminal B. Between the two luminal subtypes there are none.

Finding 2

A few hub genes show up every time

SOX10 is a transcription factor, which means it switches other genes on and off. It was a top-20 hub in all 30 rebuilds of the Basal-like and Luminal A networks, but only 3 out of 30 for Luminal B. Keratin genes like KRT5, KRT14 and KRT17 (they help build the cell's skeleton) were stable hubs in both luminal subtypes.

Before building the networks I removed the signal from fat, connective and immune tissue that gets mixed into each sample. No fat genes made the hub list, so I think that correction worked.

Finding 3

The survival result didn't hold up

One gene module per subtype passed the stability test. In TCGA, patients whose tumors had higher module activity tended to live longer (hazard ratios 0.77 to 0.82).

But in METABRIC the link basically disappeared, even though the modules themselves still held together. METABRIC has 7 times more deaths to learn from (728 vs 104), so it's not because the sample was too small. It's a negative result, but I think that's still worth reporting.

What this doesn't show

A connection here means one gene's activity helps predict another's. It doesn't prove one gene controls the other, you would need lab experiments for that. The survival results are just associations too, since treatment wasn't in the model.

Data and tools

TCGA-BRCA (1,097 tumors, from UCSC Xena) for discovery and METABRIC (1,980 tumors, from cBioPortal) for validation. Everything is written in Python with pandas, scikit-learn, SciPy and matplotlib, and checked with 125 tests. The code is on GitHub.

Favorite problem

When is a one-and-one worth more than a sure point?

In a one-and-one you only get the second free throw if you make the first one. If each shot goes in with probability p, the average score is

E = p + p2

That's more than 1 point only when p2 + p - 1 > 0, so p > (√5 - 1) / 2 ≈ 0.618. That number is 1/φ, the golden ratio upside down, which I think is pretty cool.

At this rate a one-and-one is worth 1.49 points on average, more than a sure point.
